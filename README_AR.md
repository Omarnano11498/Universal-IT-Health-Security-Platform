# Universal IT Health & Security Platform
نسخة أولية قابلة للتشغيل لفحص أجهزة Windows وLinux وmacOS، مع API مركزي ولوحة تحكم ويب بسيطة.

## ما الذي يعمل في هذه النسخة؟
- فحص محلي للقراءة فقط: معلومات النظام، CPU/RAM، مساحة الملفات، الشبكات، المنافذ المستمعة، وملخص العمليات.
- API مركزي لاستقبال نتائج الفحص وعرضها.
- لوحة تحكم ويب تفاعلية بالعربية والإنجليزية لتشغيل الفحص، عرض آخر النتائج وتصفيتها، وتنزيلها بصيغة JSON.
- تقارير JSON.
- طلب موافقة توضيحي لإعادة الفحص؛ لا ينفذ إصلاحات أو أوامر نظام.
- اختبارات آلية للوظائف الأساسية.

## ما الذي لا تدّعيه النسخة؟
هذه ليست أداة اعتماد أمني أو ماسح ثغرات شاملًا. لا تفحص كل ثغرة معروفة، ولا تضمن سلامة القطاعات المادية، ولا تنفذ فحصًا شبكيًا هجوميًا. بعض البيانات تتطلب صلاحيات مرتفعة أو أدوات نظام أصلية. تظهر الحالات غير المتاحة صراحةً بدل اعتبارها ناجحة.

## المتطلبات
- Python 3.10+
- pip

## التثبيت
### Windows PowerShell
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

### Linux / macOS
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## تشغيل فحص محلي
```bash
python -m app.cli scan --out reports/scan.json
```

يجمع الفحص بيانات الجهاز الحالي فقط، ويعمل بوضع القراءة فقط. لا يفحص أجهزة الشبكة الأخرى.

## تشغيل لوحة التحكم التفاعلية
```bash
python -m uvicorn app.server:app --host 127.0.0.1 --port 8000
```
ثم افتح http://127.0.0.1:8000، واضغط **ابدأ الفحص المحلي**. يمكن تحديث آخر نتيجة، تصفيتها، تبديل اللغة، وتنزيل JSON من الصفحة.

> الخادم مربوط افتراضيًا على loopback فقط. لا تعرضه على الشبكة قبل إعداد HTTPS والمصادقة وقواعد الوصول.

## إرسال نتيجة الفحص من CLI إلى الخادم
شغّل الخادم محليًا، ثم نفّذ:
```bash
python -m app.cli scan --post http://127.0.0.1:8000/api/scans
```
واجهات API الأساسية: `GET /api/health`، و`POST /api/scan` لبدء فحص محلي، و`GET /api/scan/results` لجلب آخر نتيجة.

## ملاحظات أمنية
- اجمع البيانات فقط من الأجهزة التي تملكها أو لديك تصريح بفحصها.
- لا تشغّل التطبيق بصلاحيات Administrator/root إلا عند الحاجة.
- نتائج الفحص مؤشرات محدودة وليست إثباتًا على أن الجهاز آمن. لا ينفذ التطبيق أي إصلاح آلي أو فحص لأجهزة بعيدة.
- قاعدة البيانات SQLite للتجربة الأولية. استخدم PostgreSQL ومصادقة قوية وTLS في النشر المؤسسي.
